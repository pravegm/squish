**Character counts** were measured by script on 26 Oct.

**Links.** `[link]` means the App Store **campaign link** for that channel (`PLAN.md` §6), e.g. `…?pt=<token>&ct=ig_bio&mt=8`. Until the app is live, use `https://pravegm.github.io/squish/`.

## 6. TikTok and YouTube Shorts adaptation

- **Same file, separate exports.** Post the clean 1080 × 1920 export to each platform, never one carrying another platform's watermark. Reposted, watermarked clips are reported to be down-ranked on Reels.
- **TikTok:**
  - Put the hook text in with TikTok's own text tool too, so it reads as native.
  - Caption: one line plus 3–5 hashtags (`#hydraulicpress #satisfying #asmr #iphoneduo #fyp` is optional; skip it if it feels spammy).
  - Use **original sound** and name it "Squish – [object]" so others can reuse it.
  - **No trending audio on anything you might later run as an ad.** TikTok ads need the Commercial Music Library.
  - Pin the C2 video to the profile.
  - The TikTok bio link appears once the account qualifies (a follower threshold applies **[verify]**). Until then, put "Squish on the App Store" in the bio text.
- **YouTube Shorts:**
  - Title = hook + object, e.g. "it creaks. then it doesn't. (glass bottle) #shorts".
  - Description: one line plus the `ct=yt_bio` link. The first 3 hashtags show above the title.
  - Add a **related video** link to the C2 Short on every other Short. Shorts can go up to 3 minutes, but keep to the 9–15 s cuts (BENCHMARK §3).
- **Cross-posting order:** Instagram first (your main account), TikTok within the hour, Shorts the same day. Reply to the first 20 comments on each.
